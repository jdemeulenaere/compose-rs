# Decision log: Android host, threads and performance

The view and activity glue, the frame loop, the hint session, jank, startup, memory, and the optimization flags. Part of the [decision log](../decisions.md): the conventions and the index by number are there. The design documents describe how things work now; each row says what was decided, why, what was rejected, and links to the section with the detail.
