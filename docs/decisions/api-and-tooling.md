# Decision log: API, naming and tooling

Names, crates and modules, semver, the edit-build loop, testing and documentation, the toolchain's and dependencies' versions. Part of the [decision log](../decisions.md): the conventions and the index by number are there. The design documents describe how things work now; each row says what was decided, why, what was rejected, and links to the section with the detail.
