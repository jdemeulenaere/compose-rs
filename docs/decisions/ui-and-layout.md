# Decision log: Modifiers, layout, input and components

Modifiers and nodes, layout and intrinsics, drawing in the tree, input, focus, semantics, animation, Material 3, navigation, platform values. Part of the [decision log](../decisions.md): the conventions and the index by number are there. The design documents describe how things work now; each row says what was decided, why, what was rejected, and links to the section with the detail.
