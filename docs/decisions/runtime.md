# Decision log: The macro, the runtime and state

`#[composable]`, groups and keys, skipping, lambdas, the call macro, the composer, recomposition, `remember`, effects, state handles, pausable composition. Part of the [decision log](../decisions.md): the conventions and the index by number are there. The design documents describe how things work now; each row says what was decided, why, what was rejected, and links to the section with the detail.

| # | Status | Decision | Alternatives rejected | Revert cost |
