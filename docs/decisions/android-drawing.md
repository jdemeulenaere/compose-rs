# Decision log: Android drawing

The display list and its replayer, render nodes and repaint boundaries, paths, shadows, layers. Part of the [decision log](../decisions.md): the conventions and the index by number are there. The design documents describe how things work now; each row says what was decided, why, what was rejected, and links to the section with the detail.
